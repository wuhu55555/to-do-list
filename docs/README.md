## 📱 项目特性

- ✅ **Vue 3 + TypeScript**：现代化前端技术栈
- ✅ **Composition API**：使用 setup 语法糖
- ✅ **SCSS 样式**：支持变量、嵌套、混入
- ✅ **响应式设计**：完美适配移动端和桌面端
- ✅ **数据持久化**：本地存储，数据不丢失
- ✅ **类型安全**：完整的 TypeScript 类型检查

## 🏗️ 技术栈

- **前端框架**：Vue 3.3.4
- **开发语言**：TypeScript 5.0.2
- **构建工具**：Vite 4.4.5
- **样式处理**：SCSS
- **类型检查**：vue-tsc

## 📁 项目结构

```
src/
├── components/          # Vue组件
├── types/              # TypeScript类型定义
├── assets/             # 静态资源
├── App.vue             # 根组件
├── main.ts             # 应用入口
└── style.css           # 全局样式
```

## 🔧 配置说明

### TypeScript 配置
项目使用 `tsconfig.json` 进行 TypeScript 配置，支持 Vue 单文件组件类型检查。

### Vite 配置
项目使用 `vite.config.js` 进行构建配置，支持 Vue 插件和路径别名。

### SCSS 配置
项目使用 SCSS 预处理器，支持变量、嵌套、混入等高级特性。

## 📱 移动端适配

项目采用响应式设计，完美适配移动端设备：

- **断点设计**：768px 为移动端断点
- **触摸优化**：按钮最小 44px 触摸区域
- **布局适配**：移动端采用垂直布局
- **字体优化**：防止 iOS 自动缩放
